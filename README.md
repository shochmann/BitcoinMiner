# Bitcoin Miner

## Overview

Simple Bitcoin mining rig made in C#/.NET.

Other complex versions of this application exist in my private repos, but this one I made public just to show the basics of how a Bitcoin is mined. 

The fundamentals of this application include:
- Getting the Block Template
- Creating Coinbase
- Creating Merkleroot
- Creating Block Header
- Creating Serialized Block
- Block Submission
